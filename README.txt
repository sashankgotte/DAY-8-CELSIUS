# Day 8 - Celsius to Fahrenheit Converter 🌡️

## 📌 Description
This is Day 8 of my 100 Days Python Programming Challenge.

This Python program converts temperature from Celsius to Fahrenheit using a mathematical formula.

## 💻 Concepts Learned
- User input using `input()`
- Type conversion using `float()`
- Mathematical operations
- Displaying output using `print()`

## 🧮 Formula
Fahrenheit = (Celsius × 9/5) + 32

## ▶️ Sample Output
```text
Enter Celsius: 25
Fahrenheit = 77.0
```
